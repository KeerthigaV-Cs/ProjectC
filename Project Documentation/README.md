# ComicCraft Project Documentation

This folder contains the complete project documentation for the ComicCraft system, organized by the major phases of the software development lifecycle. It complements the technical project repository at [ComicCraft-Project-Code/README.md](../ComicCraft-Project-Code/README.md).

## Project Overview

ComicCraft is a FastAPI-based web application that transforms a short story prompt into a five-panel comic preview and exportable PDF. The system uses AI-powered story generation, optional image generation, browser-based preview, and PDF export to simplify the comic creation workflow for users.
